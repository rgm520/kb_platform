# 企业知识库 · 接入说明

## 一、员工怎么用 WorkBuddy 接入

### 1. 找管理员要两样东西

| 要什么 | 长什么样 | 找谁 |
|---|---|---|
| 服务地址 | `http://192.0.2.19:8000` | 知识库管理员 |
| API 密钥 | `kb_` 开头的一串字符，**只显示一次** | 知识库管理员 |

> 密钥与你的平台账号绑定。别人拿你的密钥提问，审计日志里记的是你的名字。

### 2. 在 WorkBuddy 里安装技能包

拿到 `workbuddy-zs-kb.zip` 后：

1. 打开 WorkBuddy → 侧边栏 **技能市场 / Skills**
2. 选择「导入本地技能包 / 上传技能」
3. 拖入 `workbuddy-zs-kb.zip`，完成安装
4. 在技能列表里启用「企业知识库」

### 3. 配置凭据

在 WorkBuddy 所在的机器上设置两个环境变量：

```powershell
$env:ZB_KB_BASE_URL = "http://192.0.2.19:8000"
$env:ZB_KB_TOKEN   = "kb_你的密钥"
```

写成永久环境变量（管理员协助）：

```powershell
[Environment]::SetEnvironmentVariable("ZB_KB_BASE_URL", "http://192.0.2.19:8000", "User")
[Environment]::SetEnvironmentVariable("ZB_KB_TOKEN", "kb_你的密钥", "User")
```

设置后**重启 WorkBuddy**。

### 4. 验证

在 WorkBuddy 里问：

> 三级及以下子企业能不能自建数据机房？

如果回答里出现了 `[片段1]` 这样的引用标注，说明接入成功。

也可以直接在命令行验证：

```powershell
$env:ZB_KB_BASE_URL="http://192.0.2.19:8000"
$env:ZB_KB_TOKEN="kb_你的密钥"
python workbuddy-zs-kb\scripts\query.py "软件正版化率要求是多少？"
```

## 二、管理员怎么用平台

浏览器打开 `http://192.0.2.203:8000`（**知识库平台跑在 AI 服务器上，不是 NAS**；NAS 是 `192.0.2.19`），用管理员账号登录。

> 管理员初始密码**没有默认值**——首次部署时由 `python -m kbplatform.seed` 随机生成并打印一次，
> 请从部署日志里取；也可以用环境变量 `KB_ADMIN_PASSWORD` 预先指定。
> 首次登录后建议立刻在右上角「修改密码」里改掉（任何用户都能自助改）。

### 用户与权限

1. **用户与权限 → 新建用户**：填用户名、显示名、初始密码、角色
2. 在用户列表点「授权」→ 填可见目录，格式每行一条：

```
信息化管理
综合系统\2.党建（党）
人力资源共享空间
```

- 只填共享名 = 整个共享可见
- 填 `共享\子目录` = 只授权该子目录
- **普通用户看不到未授权的任何内容**（全文、向量、图谱、人工校正层四路召回全部过滤）
- 管理员不受范围限制

### 涉密目录

**涉密目录 → 标记为涉密**。填共享 + 子目录 + 说明。

命中涉密目录的查询会自动：
- 切换到**本地模型**（即使你选了云端模型）
- **不回传片段原文**（`snippet` 与 `text` 都为空）
- 在界面上明确提示

初始已标记：党建（党/团/宣/工）、`AAA2025年审计资料汇集`、`4、薪酬与福利（加密）`、`8、涉及审计`、整个 `人力资源共享空间`。

> ⚠️ **加新共享到监控范围之前，先配好涉密标记**，否则敏感目录会先被索引再补标记。

### 模型配置

**模型配置** 页签可直接增删：

- 内置预置：本地 Ollama（qwen3.5:9b-64k / 32k）、DeepSeek、通义千问、腾讯混元、智谱 GLM、Kimi、MiniMax、OpenAI
- 预置项只需填 **API Key**
- 自定义：填名称、类型（Ollama / OpenAI 兼容）、Base URL、模型名、API Key
- 勾「本地」表示该模型数据不出内网

### API 密钥

**API 密钥** 页签 → 「签发密钥」（也可在用户列表点「签发密钥」）。

- 明文**只显示一次**，请立即转交本人
- 生命周期是三步：**签发 → 吊销 → 删除**
  - **吊销**：密钥立即失效，但记录保留，方便核对是谁的、什么时候用过
  - **删除**：只有已吊销的才能彻底删掉记录。未吊销的直接点删除会被拒绝（避免误删导致某个智能体突然连不上）
- 默认有效期 90 天
- 每次调用都记入「调用审计」

### 已接入智能体

WorkBuddy 首次调用 `/api/v1/agents` 注册后，智能体会出现在这里，可看到名称、客户端 ID、最后活跃时间。

### 调用审计

记录谁、什么时候、问了什么、命中哪些文件、用了哪个模型、是否涉密。

## 三、平台是怎么工作的

```
NAS 监控目录  →  ①扫描建目录索引  →  ②分块+全文索引+向量化（Tier 1）
                                          ↓
                                     ③LLM 提炼+建图（Tier 2）
                                          ↓
                          全文检索 + 向量检索 + 图谱扩展 + 人工校正层
                                          ↓
                                   四路召回融合 → 生成带引用的答案
```

- 新文件放进 `\\192.0.2.19\信息化管理\AI知识库`，**约 1 分钟内**可被搜索，约 **30 秒/块**后进入知识图谱
- 监控目录在 `config.toml` 的 `[monitor] roots`，加共享不用改代码
- 所有产物（数据库、索引、向量）在 AI 服务器 `D:\opencode\kb\data`，**NAS 只读挂载，绝不写业务数据**

## 四、常见问题

| 现象 | 原因与处理 |
|---|---|
| WorkBuddy 说"缺少 ZB_KB_BASE_URL 或 ZB_KB_TOKEN" | 环境变量没设或没重启 WorkBuddy |
| HTTP 401 | 密钥错、已吊销或过期 → 找管理员重签 |
| HTTP 403 | 你的账号没有该目录的权限 → 找管理员在「用户与权限」里授权 |
| HTTP 429 | 当日调用超配额（默认 500 次/天）→ 明天再试或找管理员调整 |
| 答案里没有 `[片段N]` | 知识库里没检索到相关文档。此时**不要凭记忆作答** |
| 提示"因涉密已锁定本地模型" | 命中的内容在受限目录，平台已保护原文。改用平台网页版查看原文 |
| 平台打不开 | 找管理员确认服务进程在跑（`opencode` 无关，是知识库服务） |
